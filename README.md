# 🚀 axios-smart-client

A smarter, feature-packed wrapper around [Axios](https://axios-http.com/) for Node.js and browser applications — with **built-in retries**, **logging**, **rate limiting**, and **caching support** (coming soon).

> Designed for developers who love Axios but want more resilience and control — without rewriting boilerplate logic.

---

## ✨ Features

- 🔁 **Auto Retry Logic** – Retry failed requests (e.g., network errors, 5xx) automatically.  
- ⏱️ **Retry Delay** – Adjustable delay between retries.  
- 📜 **Request Logging** – View outgoing requests and their responses.  
- 🚦 **Rate Limiting** – Limit the number of requests per second (optional).  
- 💾 **Caching Layer** *(Coming Soon)* – Cache GET responses to reduce API load.  
- ⚙️ **Full Axios Compatibility** – Pass **any standard Axios config** — baseURL, headers, params, etc.  
- 🦺 **TypeScript Support** – Written in TypeScript with full IntelliSense and types.
